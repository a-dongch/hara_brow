## 🆘 문제 해결

### Q: 네비게이션이 작동하지 않아요
A: jQuery가 제대로 로드되었는지 확인하고, 브라우저 콘솔에서 오류 확인

### Q: 애니메이션이 너무 느려요
A: css/style.css에서 transition duration 값을 조정

### Q: 모바일에서 레이아웃이 깨져요
A: 브라우저 캐시를 지우고 다시 로드

### Q: FAQ가 열리지 않아요
A: js/main.js가 제대로 로드되었는지 확인
